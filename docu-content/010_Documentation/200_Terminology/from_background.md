# Glossary Additions (from Latest Pages)

### 80/20 Rule (Pareto Principle)
A principle stating that roughly 80% of results come from 20% of causes. In Freon’s context, used to emphasize focusing development on simplifying the majority of a system.

### Abstract Syntax Tree (AST)
The structured representation of a program or model that Freon editors manipulate directly, instead of raw text.

### Alan Kay Quote
“Simple things should be simple, complex things should be possible.” — the guiding design philosophy behind Freon.

### Balanced Expressions
Automatic restructuring of expression trees in Freon to reflect correct operator precedence when editing expressions.

### Clinical Research Coordinator (CRC)
Role used in TriRadial’s case study — domain experts who manage clinical trials using a DSL built with Freon.

### DSL (Domain-Specific Language)
A focused, specialized language designed for a particular domain. Freon provides tooling to define, edit, and use DSLs.

### Embedding Freon
Integrating a Freon editor directly into a web application, often through the Svelte component model.

### Expressions (Editing)
Complex editable structures within Freon editors that mimic text-like behavior while maintaining AST integrity.

### Figure Component
A Svelte component used to include images with captions and figure numbering in Freon documentation.

### FreNodeReference
A Freon class representing references in the model by name or path, ensuring models remain tree-shaped rather than graph-based.

### Freon
A framework for building web-based DSL editors; also the Frisian word for “friend,” symbolizing openness and accessibility.

### Freon Interpreter Framework
A runtime component used to simulate DSL behavior, as shown in TriRadial’s CRCHub application.

### LionWeb
An initiative for web-based interoperability of modeling tools, using standardized JSON formats and protocols for models and languages.

### LionWeb Repository
A server implementation that stores models using the LionWeb protocol; Freon can connect to it for model persistence.

### MDENet
A community and forum for model-driven engineering; Freon was presented and demonstrated here in 2023.

### Minimal Viable Product (MVP)
Freon’s principle of providing essential language engineering capabilities first, leaving complex customization to the user.

### Model Unit
A modular part of a Freon model, similar to a source code module, enabling large models to be divided across files.

### Name-Based Reference
A reference type in Freon identified by name rather than object ID, allowing flexible, lightweight linking between model elements.

### Object Constraint Language (OCL)
A formal language for expressing rules and constraints on UML models, co-created by Jos Warmer.

### Pareto Principle
See *80/20 Rule.*

### Projection
The visual representation of a model/AST in Freon’s projectional editor.

### Projectional Editing
An editing paradigm where users manipulate the model’s AST directly instead of modifying plain text.

### SvelteKit
A framework used to build the Freon documentation website.

### Syntax Highlighting
Color styling of code blocks in Freon documentation, provided through **mdsvex** and **Prism** using VS Code themes.

### TriRadial Solutions
A company using Freon to develop a DSL for clinical research coordination and scheduling simulations.

### UML (Unified Modeling Language)
An industry-standard modeling language co-developed by Jos Warmer, supported by OCL for defining constraints.

### Word Cloud Tree
A visual element on the documentation site created using *wordclouds.com*, representing Freon’s terminology.
