# Information for Freon documentation Developers

In this folder you can find various files that describe part of the documentation repository that will 
help you to understand where and how to change and augment the Freon documentation.

The documentation site is build using SvelteKit, so you need to have some understanding of that tool 
(see https://svelte.dev/docs/kit/introduction). 

Furthermore, we use a number of tools in the scripts section. 
You have to understand these tools only if you want to understand or alter the markdown-to-svelte generator: 
Markdown (https://www.markdownguide.org/), embedme (https://github.com/zakhenry/embedme#readme), 
mdsvex (https://github.com/pngwn/MDsveX#readme), remark (https://remark.js.org/).

We suggest that you start with understanding the structure of the repo, and then follow up with one of the 'how-to' guides.
Thanks for your efforts and support.
